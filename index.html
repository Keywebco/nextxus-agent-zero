What Agent Zero Is

Agent Zero is the seed. Every new Federation site can grow from this one self-contained file: plain HTML that any crawler can read, a small settings block for the persona, and no build step at all.

  1. Copy the repository.
  2. Edit the settings block at the top of the page: name, role, emblem, tagline, ring level.
  3. Publish it on GitHub Pages or any static host.
  4. The new node joins the Federation with the same readable, accessible structure.

What Agent Zero Is Becoming

Agent Zero is being built into the Federation's autonomous builder: an agent that writes its own code and ships it without a human doing the mechanics.

  • Self-writing code. It drafts pages and scripts through the free API stack, with DeepSeek doing the heavy code reasoning.
  • Autonomous GitHub builds. It commits straight to Federation repositories through the GitHub API and publishes through GitHub Pages.
  • Free API stack. DeepSeek, MiMo, Cerebras, Groq, and Mistral, with automatic fallback when one provider fails.
  • Checked before it counts. Nothing is reported done until a live check confirms it. The human keeps the final say on decisions.

Status, stated plainly: the seed template is live today. The autonomous builder is in development.
