# ◈ Agent Zero — NextXus Federation Satellite Node Template

The seed from which all Federation nodes grow.

## What Is This?

Agent Zero is the **base satellite node template** for the NextXus Federation Ring Architecture. Any new satellite site spawns from this single `index.html` file.

## How To Spawn A New Node

1. Fork or copy this repo
2. Edit the `CONFIG` block at the top of `index.html`
3. Change persona name, role, emoji, tagline, and ring level
4. Deploy to GitHub Pages (or any static host)

## Features

- **Single self-contained file** — no build step, no dependencies
- **Pre-rendered semantic HTML** — readable by AI crawlers without executing JavaScript
- **Live Federation sync** — fetches shared mind content at runtime
- **Configurable persona** — name, role, emoji, tagline, ring level
- **Active motion** — CSS pulse animation on persona emblem
- **Mobile responsive** — works on all screen sizes
- **Federation aesthetic** — dark background, gold accents, monospace typography
